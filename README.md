# gautschmi.ch

Selbst gemachtes Lernmaterial für Polygrafinnen und Polygrafen EFZ an der Schule für Gestaltung Zürich.

Die Website wird über GitHub Pages veröffentlicht. Die Startseite `index.html` entsteht mit `python3 quellen/build.py` aus `quellen/` und `materialien.json`. Wie neues Material dazukommt, steht in `CLAUDE.md`.
